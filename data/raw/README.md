# 数据来源说明

项目使用 UCI Machine Learning Repository 的 Bike Sharing 数据集（数据集编号 275）。数据包含 2011—2012 年 Capital Bikeshare 系统的小时和日租车量，以及季节、天气、温度、湿度、风速和用户类型等字段。

- 官方页面：https://archive.ics.uci.edu/dataset/275/bike%2Bsharing%2Bdataset
- DOI：https://doi.org/10.24432/C5W894
- 许可：CC BY 4.0
- 本项目使用：`uci-bike-sharing/hour.csv`
- 主要文件：`hour.csv`（17,379 条小时记录）、`day.csv`（731 条日记录）
