# 系统设计说明

## 1 总体架构

项目采用分层模块结构：输入层负责读取数据，处理层负责清洗，分析层负责指标计算，展示层负责输出图表，入口层负责串联流程。

## 2 接口说明

### `load_bikeshare(path)`

输入 CSV 路径，输出 DataFrame；缺少必需字段时抛出 `ValueError`。

### `clean_bikeshare(frame)`

转换日期和数值字段，删除关键字段为空的记录，计算临时用户占比。

### `hourly_summary(frame)` / `weather_summary(frame)`

分别返回小时平均租车量和天气条件平均租车量。

### `create_charts(frame, output_dir)`

生成小时、用户类型、天气影响三张 PNG 图并返回文件路径列表。

## 3 异常处理

- 文件路径错误：保留 pandas 的文件错误信息。
- 字段缺失：提前列出缺少的字段。
- 日期或数值格式错误：转为缺失值后在清洗阶段删除。
- 输出目录不存在：自动创建。

## 4 可扩展设计

后续可以增加 `models/` 预测模块、`dashboard/` 交互页面和 `storage/` 数据库模块，且不需要修改现有读取和清洗接口。
