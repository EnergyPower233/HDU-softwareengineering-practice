# 城市共享单车需求分析（Skeleton）

## 目标

对城市共享单车骑行 CSV 数据进行读取、清洗、统计分析与可视化，帮助用户了解骑行高峰、用户类型和热门起点站，并为后续真实数据接入和交互式展示预留接口。

## 用户与场景

- 学生：用于展示完整的数据分析项目流程和实验结果。
- 教师/评审：运行命令即可复现核心结果，检查源码质量与文档完整性。

## 功能需求

1. 校验输入数据是否包含骑行编号、起止时间、起止站点和用户类型字段。
2. 规范时间类型，计算骑行时长并删除异常记录。
3. 输出按小时、用户类型和起点站汇总指标。
4. 生成至少三张有标题、坐标轴和标签的图表。
5. 支持通过命令行替换输入文件和输出目录。

## 非功能需求

- 离线可运行、结果可复现、模块职责清晰。
- 关键函数有文档字符串，提供最小单元测试。
- 真实数据接入时需记录来源、授权与隐私合规情况。
