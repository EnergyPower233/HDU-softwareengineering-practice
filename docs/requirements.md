# 需求分析（Skeleton）

## 目标

对城市空气质量 CSV 数据进行读取、清洗、统计分析与可视化，帮助用户比较不同城市的平均 AQI，观察时间趋势，并为后续真实数据接入和交互式展示预留接口。

## 用户与场景

- 学生：用于展示完整的数据分析项目流程和实验结果。
- 教师/评审：运行命令即可复现核心结果，检查源码质量与文档完整性。

## 功能需求

1. 校验输入数据是否包含日期、城市、PM2.5、PM10、NO2、AQI 字段。
2. 规范日期与数值类型，删除关键字段缺失记录。
3. 输出按城市汇总和按日期汇总指标。
4. 生成至少两张有标题、坐标轴和图例/标签的图表。
5. 支持通过命令行替换输入文件和输出目录。

## 非功能需求

- 离线可运行、结果可复现、模块职责清晰。
- 关键函数有文档字符串，提供最小单元测试。
- 真实数据接入时需记录来源、授权与隐私合规情况。
